Director 1.1.0 for OBS Studio 32.2.x (Windows x64)
==================================================

Director is one install of two OBS plugins that drive a Synesthesia VJ feed from
the DJ mix: Palette Director locks the picture to neon palettes and owns the beat
clock; Scene Director turns that clock into MIDI Next / Previous, so a Synesthesia
playlist switches on the beat.

Director 1.1.0 = Palette Director 1.2.0 + Scene Director 2.0.0.


1. What is in this zip
----------------------
  palette-director/   Palette Lock filter, Palette Director dock, Music dock
  scene-director/     Scene Director source, Scene Director dock, MIDI Director dock
  INSTALL.txt         this file
  LICENSE             GPL-2.0

Each component keeps its own INSTALL.txt in its own repository, with the full
detail for that component.


2. Requirements
---------------
  - Windows 10 or 11, 64-bit.
  - OBS Studio 32.2.x (both plugins are built against 32.2.2).
  - Synesthesia with a Pro licence: its Spout input carries the picture into OBS,
    and it must accept MIDI input to drive its playlist.
  - A virtual MIDI port: loopMIDI, or a Windows MIDI Services loopback pair. It
    carries Scene Director's Next / Previous from OBS to Synesthesia.
  - The DJ mix as one OBS audio source (an "Audio Input Capture" is enough).
  - Optional: a MIDI controller for the MIDI Director dock.


3. Install
----------
1. Close OBS.
2. If an older install of either component is present, delete its folder under
     C:\ProgramData\obs-studio\plugins\
   before copying this one.
3. Unzip director-1.1.0-windows-x64.zip and copy the two folders
   "palette-director" and "scene-director" into
     C:\ProgramData\obs-studio\plugins\
   so that these files exist:
     C:\ProgramData\obs-studio\plugins\palette-director\bin\64bit\palette-director.dll
     C:\ProgramData\obs-studio\plugins\palette-director\data\sets\neon-default.json
     C:\ProgramData\obs-studio\plugins\scene-director\bin\64bit\scene-director.dll
4. Start OBS. Help > Log Files > View Current Log should show
     [palette-director] plugin loaded successfully (version 1.2.0)
     [scene-director] plugin loaded successfully (version 2.0.0)
   If one of the lines is missing, check the folder layout above.


4. First run
------------
A minimal working rig, in order:

1. Synesthesia: set up the Spout input, and in its MIDI settings make sure the
   playlist can take MIDI input. Leave Synesthesia running.
2. OBS: add the Spout source that carries Synesthesia into a scene.
3. Palette Lock: right-click that source > Filters > + > Palette Lock. Put it ABOVE
   any finishing filters (CRT etc.). Press "Load file..." and open
     C:\ProgramData\obs-studio\plugins\palette-director\data\sets\neon-default.json
   the set is copied into your set folder and appears in the Set list.
4. Palette Director dock: Docks menu > "Palette Director". The top strip shows the
   filter, a section chip (GROOVE / BREAKDOWN / DROP), the lock state, Coverage and
   the palette pads; BPM, confidence and the last 64 beats are in the Music dock.
   Set-up opens the tabs (Set, Palettes, Look, Changes, Director, Log).
5. Audio: make sure the DJ mix is an OBS audio source (for example an Audio Input
   Capture named "Mixer"), then pick it in the Music dock > Audio source. Set the
   Fallback BPM for silent feeds. The BPM, the beat lights and the section should
   now follow the music.
6. Scene Director: add a "Scene Director" source to a scene and leave Clock on
   "Follow Palette Director". It renders nothing: it holds the set's settings and
   drives the MIDI.
7. MIDI to Synesthesia:
     a. Install the virtual MIDI port (loopMIDI or a Windows MIDI Services loopback
        pair) and start it.
     b. Open the Scene Director dock (Docks menu > "Scene Director"), press Rescan
        under MIDI out and pick the port. The link chip turns green.
     c. In Synesthesia's MIDI settings, enable that port as a MIDI input.
     d. In Synesthesia's MIDI mapping, enter MIDI learn on the playlist's "next"
        control and press Next in the Scene Director dock; then do the same for
        "previous" with Prev and save.
   From then on, a breakdown and a drop move the playlist by itself, on the beat.
8. Optional: Docks menu > "MIDI Director", press Learn, move a control. A pad bound
   to "Scene Director: Next scene" and another to "Scene Director: Previous scene"
   is a good first pair.
9. Press Save on the Palette Director dock > Set tab. The set (palettes, look,
   changes, lock behaviours) is written to
     Documents\PaletteDirector\sets\


5. Where things live
--------------------
  C:\ProgramData\obs-studio\plugins\palette-director   the Palette Director plugin
  C:\ProgramData\obs-studio\plugins\scene-director     the Scene Director plugin
  Documents\PaletteDirector\sets\                      your sets, one JSON per set
  the scene collection                                 clock, MIDI out device, the
                                                       switch rules, MIDI mappings

Sets are also stored inline in each Palette Lock filter, so a scene collection keeps
working if a set file is missing. To uninstall cleanly, remove both plugin folders;
your sets in Documents\PaletteDirector\sets\ are kept.


6. Troubleshooting
------------------
  - No dock in the Docks menu: that plugin did not load. Check the log for the two
    "plugin loaded successfully" lines and the folder layout in section 3.
  - Nothing changes with the music: check the Music dock meter. LEVEL well below
    -30 dBFS means raise Input gain; if the meter is pinned at the top, lower it.
    If the kick light misses kicks, raise Kick sensitivity.
  - No BPM at all: no audio source is selected, or it is silent. The Director then
    runs at the Fallback BPM and nothing changes on its own.
  - The Scene Director link chip stays grey: no MIDI out device is selected. Press
    Rescan and pick the virtual port.
  - The Scene Director link chip is red ("Port not found"): the port is not
    running. Start loopMIDI (or whatever creates the port); it is picked up again
    automatically.
  - The playlist does not move although Scene Director sends: enable the port as a
    MIDI input in Synesthesia's MIDI settings, and check that the playlist's next /
    previous controls were MIDI-learned and saved.
  - Everything fires twice: one control is bound both to a Scene Director hotkey
    (through MIDI Director) and to the playlist control in Synesthesia. Bind it in
    one place only.
  - Synesthesia does not list the Spout sender: if OBS was force-closed, an old
    sender name can stay registered. Close OBS normally, or rename the sender.
  - The Scene Director clock shows "free": no Palette Lock found, or Palette
    Director is older than 1.1. Check the log for "clock following Palette
    Director".


7. Uninstall
------------
Close OBS and delete
  C:\ProgramData\obs-studio\plugins\palette-director
  C:\ProgramData\obs-studio\plugins\scene-director
Your sets in Documents\PaletteDirector\sets\ are kept.
