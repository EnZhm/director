Director 2.0.0 for OBS Studio 32.2.x (Windows x64)
=================================================

Director is four OBS plugins driven by the DJ mix. Music Director listens to the
mix and keeps the one beat clock. Palette Director (palettes), Clip Director
(video clips) and Scene Director (Synesthesia playlist over MIDI) follow it, so a
breakdown or a drop changes the palette, cuts the clip and moves the Synesthesia
playlist on the same beat.

Every plugin in this zip is version 2.0.0.


1. What is in this zip
----------------------
  music-director/     the clock, the Music dock, the MIDI Director dock
  palette-director/   the Palette Lock filter and the Palette Director dock
  clip-director/      the Clip Director source and dock
  scene-director/     the Scene Director source and dock (MIDI out to Synesthesia)
  INSTALL.txt         this file
  LICENSE             GPL-2.0
  SHA256SUMS.txt      checksums of every file in the four plugin folders


2. Requirements
---------------
  - Windows 10 or 11, 64-bit.
  - OBS Studio 32.2.x (all four plugins are built against 32.2.2).
  - The DJ mix as one OBS audio source (an "Audio Input Capture" is enough).
  - For Synesthesia: a Spout input for the OBS picture, MIDI input for the
    playlist, and a virtual MIDI port (loopMIDI, or a Windows MIDI Services
    loopback pair).

Palette Director, Clip Director and Scene Director need Music Director. Without
it they idle: no crash, one log line, and their dock says "Waiting for Music
Director".


3. Install
----------
  1. Close OBS.
  2. Upgrading from 1.x: delete these folders if they exist:
       C:\ProgramData\obs-studio\plugins\palette-director
       C:\ProgramData\obs-studio\plugins\clip-director
       C:\ProgramData\obs-studio\plugins\scene-director
  3. Copy the four folders from this zip into C:\ProgramData\obs-studio\plugins\
     so that these files exist:
       C:\ProgramData\obs-studio\plugins\music-director\bin\64bit\music-director.dll
       C:\ProgramData\obs-studio\plugins\palette-director\bin\64bit\palette-director.dll
       C:\ProgramData\obs-studio\plugins\clip-director\bin\64bit\clip-director.dll
       C:\ProgramData\obs-studio\plugins\scene-director\bin\64bit\scene-director.dll
  4. Optional: check the files against SHA256SUMS.txt. In PowerShell, from the
     unzipped folder:
       Get-FileHash -Algorithm SHA256 .\music-director\bin\64bit\music-director.dll
  5. Start OBS. Help > Log Files > View Current Log shows, once per plugin:
       [music-director] plugin loaded successfully (version 2.0.0)
       [palette-director] plugin loaded successfully (version 2.0.0)
       [clip-director] plugin loaded successfully (version 2.0.0)
       [scene-director] plugin loaded successfully (version 2.0.0)


4. What carries over from 1.x
-----------------------------
  - Palette Lock filters, palettes and sets load exactly as saved, spectrum
    palettes included.
  - Audio settings move to Music Director on first load: the audio source, input
    gain, kick sensitivity, fallback BPM, phrase length and any bound clock
    hotkeys, taken from the first enabled Palette Lock filter that has an audio
    source. The log line "[music-director] migrated audio settings from ..."
    names the filter it used.
  - Clip Director sources load unchanged.
  - MIDI Director mappings load unchanged, now in Music Director. Mappings that
    targeted Clip Director 1.1's Synesthesia OSC hotkeys (cd_syn_*) have nothing
    to press: map those controls to scene_director_next / scene_director_prev.


5. First run
------------
  1. Music Director dock: pick the mix as the audio source. The BPM, the beat
     lights and the section (GROOVE / BREAKDOWN / DROP) follow the music.
  2. Add the filter "Palette Lock" to the source that carries the picture, then
     choose a set in the Palette Director dock (the bundled set is Neon Default).
  3. Add a "Clip Director" source with your clip folders, tagged Groove,
     Breakdown or Drop. For Synesthesia, put a Spout Filter on it.
  4. Add a "Scene Director" source and pick the virtual MIDI port as its MIDI out
     (dock > MIDI out > Rescan > the port).
  5. Test without music: Force breakdown and Drop now in the Music Director dock
     change the palette, cut the clip and send the Synesthesia Next on the next
     beat.


6. Synesthesia playlist: Next and Prev
--------------------------------------
  1. In Synesthesia's MIDI settings, enable the virtual port as a MIDI input.
  2. In Synesthesia's MIDI mapping, MIDI-learn the playlist's "next" control, then
     press Next in the Scene Director dock.
  3. Do the same for "previous" with Prev, then save Synesthesia's mapping.
  Breakdowns and drops then send Next by themselves. Automatic section changes
  respect a 16-beat cooldown; forced sections and Next / Prev from the buttons,
  the hotkeys or MIDI always go through.


7. MIDI Director: map a controller
----------------------------------
  1. Docks > MIDI Director. Pick the controller as the MIDI input (Rescan if it
     was plugged in after OBS started).
  2. Select the OBS hotkey to drive in the list, for example md_drop_now,
     md_force_breakdown, md_tap_tempo, PaletteDirector.Next.<filter>, cd_skip,
     scene_director_next.
  3. Click Learn and move the pad, key or knob. Choose Press / release or Toggle.
  Mappings are saved with the scene collection.


8. Remove
---------
  Close OBS and delete the four folders from C:\ProgramData\obs-studio\plugins\.
  Scene collections keep their settings; the plugins pick them up again if they
  are reinstalled.
